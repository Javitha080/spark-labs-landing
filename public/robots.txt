# Google-specific
# /api/ is intentionally NOT blocked for Googlebot: its headless Chrome runs
# the React app, which calls /api/events and other endpoints to populate the
# page. If we block /api/ here, the live render fails (404/403 in the page
# resources), and Googlebot captures a broken screenshot. Other bots in the
# / and Yandex sections below keep the /api/ block — they don't run JS, so
# the API endpoints are useless to them and only waste crawl budget.
